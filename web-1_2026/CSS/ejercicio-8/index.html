Diseño Responsive

Adaptar una página web para que pueda visualizarse correctamente en diferentes tamaños de pantalla.

Requisitos

  • Crear un contenedor principal.
  • Crear un encabezado.
  • Crear un área de contenido.
  • Utilizar un ancho definido para escritorio.
  • Adaptar el ancho del contenido para dispositivos móviles.

Conceptos

  • Media Queries.
  • @media (max-width: 768px)
  • Responsive Design.
